# Cuisine de INNHS

Discover the Flavors Around You. A student food discovery website for Ilocos Norte National High School.

## Edit your content
- **Food names, descriptions, prices, eatery names, photo file names:** edit `js/data.js` (open it on GitHub, click the pencil, type between the quotes, then Commit changes).
- **Photos:** upload into the `images` folder using the names listed in `images/README.txt`.
- **Other text** (About page, headlines): edit the `.html` files the same way.

Never invent eateries or prices. Only add real ones you have checked.

## Files
- `index.html`, `about.html`, `meals.html`, `snacks.html`, `gallery.html`: the five pages
- `css/style.css`: colors and layout
- `js/data.js`: your content (edit this)
- `js/main.js`: animations, search, falling food (no need to edit)
